개인정보처리방침

EconomyMaker / StorybookEconomy 업로드 도구 · 시행일: 2026-10-25

이 도구는 채널 운영자 본인이 자신의 유튜브 채널(모아 씨의 경제 동화, 세상의 내력)에 영상을 올리기 위해 사용하는 개인용 프로그램이며, 일반 사용자에게 제공되지 않습니다.

사용하는 Google 데이터: YouTube Data API 권한(youtube.upload, youtube.readonly)으로 운영자 본인 채널의 기본 정보(채널 ID, 이름)를 확인하고, 본인이 만든 영상과 썸네일을 업로드합니다.

저장: 로그인 토큰은 운영자 PC에만 Windows 암호화(DPAPI)로 저장되며, 외부 서버로 전송하거나 공유하지 않습니다.

제3자 제공: 어떤 데이터도 판매하거나 제3자에게 제공하지 않습니다.

철회: Google 계정 > 보안 > 타사 앱 액세스에서 언제든 권한을 해제할 수 있습니다.
